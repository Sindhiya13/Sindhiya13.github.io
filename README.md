# Sindhiya A — QA Portfolio

A responsive, dark-themed QA portfolio website featuring manual testing, Selenium/Python/Pytest automation, projects, experience, education, and contact links.

## Preview locally
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public repository named `Sindhiya13.github.io`.
2. Upload `index.html` to the repository root and commit it to `main`.
3. Open **Settings → Pages** and select `main` and `/ (root)` if required.
4. Wait for GitHub Pages deployment, then visit `https://sindhiya13.github.io/`.

## Personalize before publishing
- Verify internship dates and all descriptions.
- The terminal in the hero section is a design illustration; it is not a live test run.
- Add direct repository URLs for the Smart Voice Assistant and Photography Booking System if you publish them.
- Add a resume PDF link if you want recruiters to download your resume.
